# آموزشگاه رانندگی تخت جمشید — نسخه ۵

## محتویات
- `index.html`: صفحه اصلی با چیدمان بخش‌به‌بخش از بالا به پایین
- `course.html`: کلاس متنی آموزش آیین‌نامه
- `styles.css`: طراحی واکنش‌گرا با تم سرمه‌ای و فیروزه‌ای
- `app.js`: رفتار فرم‌ها و تعاملات
- `assets/`: عکس‌های اصلی آموزشگاه و برش‌های تصویری استخراج‌شده از ماکاپ طراحی

## انتشار در GitHub Pages
تمام فایل‌ها و پوشه‌ها را در ریشه مخزن GitHub قرار بده و در Settings → Pages، شاخه اصلی و پوشه root را انتخاب کن.

## نکات
- تصاویر داخل `assets/` با مسیرهای نسبی استفاده شده‌اند تا در GitHub Pages نیز بارگذاری شوند.
- فرم‌ها برای ثبت خودکار در Google Sheets به تنظیم آدرس Web App در `app.js` نیاز دارند.
- صفحه اصلی شامل کارت آزمون و نتیجه آزمون نیست؛ کلاس آیین‌نامه صفحه مستقل دارد.
- تصاویر کوچک مربیان، صرفاً نمونه بصری داخل ماکاپ هستند؛ برای نمایش عکس واقعی مربیان باید تصاویر مجاز و باکیفیت آن‌ها جایگزین شوند.


## به‌روزرسانی تصاویر
تصاویر سایت برای نمایش شفاف‌تر در دسکتاپ و موبایل بهینه شده‌اند. عکس‌های واقعی تابلو و محوطه آموزشگاه حفظ شده‌اند و تصاویر نمایشی کلاس و مربیان از برش‌های تصویری باکیفیت‌تر ساخته شده‌اند. تصاویر مربیان نمونه هستند و باید با عکس واقعی مربیان جایگزین شوند.


نسخه آموزشی توسعه‌یافته: صفحه course.html شامل ۶ جلسه تئوری و ۲ جلسه عملی است؛ exams.html شامل ۲۰ آزمون تمرینی ۳۰ سؤالی تعاملی با ۱۰ سؤال در هر آزمون است. سؤال‌ها تمرینی و تألیفی‌اند و نباید به‌عنوان استخراج کامل و تأییدشده از PDF معرفی شوند.


## ساختار دوره ۸ جلسه‌ای
- کلاس آیین‌نامه به ۸ جلسه مرحله‌ای تقسیم شده است: ۶ جلسه تئوری و ۲ جلسه عملی.
- جلسه اول در ابتدا باز است؛ تکمیل هر جلسه، جلسه بعدی را باز می‌کند.
- پیشرفت با `localStorage` روی همان مرورگر/دستگاه ذخیره می‌شود و به سرور ارسال نمی‌شود.
- تصاویر درس‌ها با ابعاد اصلی استفاده شده‌اند، به‌صورت واکنش‌گرا نمایش داده می‌شوند و برای بارگذاری بهتر از lazy loading استفاده می‌کنند.
- محتوای آموزشی راهنمای یادگیری است؛ برای جزئیات قانونی و اعداد، آخرین نسخه رسمی آیین‌نامه را بررسی کنید.


### تصاویر انتخاب مربی
تصاویر مربی خانم و آقا با کیفیت JPEG بالا ذخیره شده‌اند و برای کارت‌های انتخاب مربی در دسکتاپ و موبایل بهینه شده‌اند. این تصاویر نمونه‌های تولیدشده/نمایشی هستند و لزوماً مربیان واقعی آموزشگاه نیستند.


## نسخه بدون پوشه برای GitHub Pages
تمام فایل‌های این بسته در یک سطح قرار دارند. فایل‌های تصویر با پیشوند `img-` نام‌گذاری شده‌اند و مسیرهای HTML/CSS به‌روزرسانی شده‌اند. همه فایل‌ها را از حالت فشرده خارج کنید و همگی را یکجا در صفحه مخزن GitHub با گزینه Add file → Upload files بکشید؛ پوشه‌ای لازم نیست. فایل `index.html` باید در ریشه مخزن باشد.


## تغییرات این نسخه
- دکمه «مسیریابی در نقشه» برای جست‌وجوی نشانی آموزشگاه در Google Maps اضافه شده است؛ لطفاً نتیجه مکان را پیش از انتشار نهایی بررسی کنید.
- صفحه آزمون‌ها زمان‌سنج ۲۰ دقیقه‌ای، ثبت نتیجه، حدنصاب تمرینی ۲۶ از ۳۰، نمایش پاسخ و توضیح، و ذخیره تاریخچه روی همان مرورگر دارد. حدنصاب و زمان، تنظیمات تمرینی این سایت‌اند و به‌عنوان ضابطه رسمی معرفی نمی‌شوند.
- بانک سؤال تأیید رسمی نشده و برخی سؤال‌ها در آزمون‌های مختلف تکرار می‌شوند؛ پیش از معرفی به‌عنوان محتوای رسمی باید با منبع روز پلیس راهور تطبیق داده شود. پیوند متن مقررات صرفاً مرجع قوانین است، نه تأیید بانک سؤال.
- فرم «درخواست رزرو جلسه عملی» نام، موبایل، ترجیح مربی، نوع درخواست، تاریخ و بازه زمانی پیشنهادی را جمع‌آوری می‌کند. این درخواست، رزرو قطعی نیست و پس از هماهنگی آموزشگاه تأیید می‌شود.
- فرم‌های ثبت‌نام، انتخاب مربی و رزرو عملی فقط پس از تنظیم آدرس Google Apps Script Web App در `app.js` به endpoint ارسال می‌شوند. اگر آدرس تنظیم نشده باشد، فرم پیام راهنما می‌دهد و داده‌ای ارسال نمی‌کند.


## بهبودهای جدید این نسخه
- نوار ثابت تماس، ثبت‌نام و درخواست تمرین در موبایل.
- دسترسی سریع از صفحه اصلی به کلاس آیین‌نامه، ۲۰ آزمون تمرینی، کارنامه و تحلیل عملکرد، و مراحل گواهینامه.
- بخش نظرات هنرجویان به‌طور کامل حذف شده است.
- کارنامه آزمون‌ها در همان مرورگر/دستگاه ذخیره می‌شود و سامانه مدیریتی یا همگام‌سازی بین دستگاه‌ها نیست. نمودار رشد و نقاط قوت/نیازمند تمرین بر اساس آزمون‌های انجام‌شده ساخته می‌شود.
- بخش نظرات به‌طور کامل حذف شده است.
- صفحه آموزش دارای برنامه ۸ روزه ویدئویی است؛ روزهای ۱ تا ۳ به ویدیوهای مشخص و روزهای ۴ تا ۸ به جست‌وجوی موضوعی ویدیوهای فارسی پیوند دارند.


## نسخه توسعه‌یافته: پنل مدیریت، پیگیری درخواست‌ها، آمار و صفحه معرفی

این بسته شامل صفحه `proposal.html` برای معرفی ارزش تجاری سایت، متادیتای پایه و داده ساختاریافته کسب‌وکار، و فایل `Admin.html` برای رابط پنل مدیریت است. بخش‌های زیر با پیکربندی و انتشار سرویس پشتیبان کار می‌کنند؛ صرفاً بارگذاری ZIP در GitHub باعث فعال شدن دیتابیس یا پنل نمی‌شود.

### راه‌اندازی کامل سرویس مشترک (یک بار)

1. یک Google Sheet جدید بسازید. از URL شیت، شناسه بین `/d/` و `/edit` را بردارید و به جای `PASTE_GOOGLE_SHEET_ID_HERE` در `google-apps-script.gs` بگذارید.
2. در Google Apps Script یک پروژه بسازید. محتوای `google-apps-script.gs` را در فایل `Code.gs` کپی کنید و یک فایل HTML با نام دقیق `Admin` بسازید؛ محتوای فایل `Admin.html` همین بسته را در آن قرار دهید.
3. در Project Settings بخش Script properties، کلید `ADMIN_PASSWORD` بسازید و یک رمز طولانی و یکتا (حداقل ۱۲ کاراکتر) قرار دهید. این رمز را داخل فایل سایت یا در GitHub قرار ندهید.
4. در تنظیمات Deploy > New deployment > Web app، اجرای اسکریپت را با حساب مالک (Me) انجام دهید و دسترسی را طوری تنظیم کنید که فرم‌های سایت بتوانند درخواست را ارسال کنند. سطح دسترسی به سیاست حساب Google شما بستگی دارد؛ شیت را عمومی نکنید.
5. URL نهایی انتشار که به `/exec` ختم می‌شود را در مقدار `SHEETS_WEB_APP_URL` در ابتدای `app.js` بگذارید و فایل `app.js` را در GitHub به‌روزرسانی کنید. از URL تست `/dev` استفاده نکنید.
6. برای پنل مدیریت، آدرس Web App را با `?action=admin` باز کنید. با رمز مدیریت وارد شوید. از پنل می‌توانید وضعیت درخواست‌ها را به «جدید»، «تماس گرفته شد»، «ثبت‌نام نهایی شد» یا «لغو شد» تغییر دهید.
7. تست واقعی: یک درخواست آزمایشی ارسال کنید و وجود ردیف در شیت `درخواست‌ها` را بررسی کنید؛ آمار کلیک‌ها را پس از چند بازدید بررسی کنید. به دلیل محدودیت `no-cors`، پیام مرورگر به‌تنهایی رسیدن داده را اثبات نمی‌کند؛ شیت را کنترل کنید.

### شیت‌ها و امنیت

- `درخواست‌ها`: اطلاعات تماس، نوع درخواست، زمان پیشنهادی و وضعیت پیگیری.
- `آمار سایت`: رویدادهای کلی مانند بازدید صفحه و کلیک تماس/ثبت‌نام/درخواست تمرین؛ نام و شماره تماس در آمار ذخیره نمی‌شود.
- رمز مدیریت در Script Properties نگهداری می‌شود و ورود، نشست کوتاه‌مدت دارد. رمز قوی انتخاب کنید و لینک پنل را عمومی تبلیغ نکنید.
- فرم عمومی به‌تنهایی تأیید هویت هنرجو نیست؛ برای استفاده عملی، از درج اطلاعات حساس غیرضروری پرهیز کنید و دوره‌ای داده‌های غیرلازم را حذف کنید.

### صفحه معرفی امکانات

`proposal.html` برای ارائه به مدیر آموزشگاه ساخته شده است. هزینه‌ها، زمان پاسخ‌گویی، دامنه، مالکیت و پشتیبانی عمداً به‌صورت عدد ساختگی نوشته نشده‌اند و باید در توافق واقعی تعیین شوند.

### سئو و آمار

متادیتای پایه و JSON-LD در صفحه اصلی اضافه شده است؛ این موارد کمک می‌کنند موتور جست‌وجو محتوا و کسب‌وکار را بهتر بفهمد، اما رتبه یا تعداد هنرجو تضمین نمی‌کنند. داده‌های تحلیلی فقط بعد از تنظیم URL و جمع‌آوری واقعی نمایش داده می‌شوند.


## اپلیکیشن هنرجویان
برای فعال شدن دکمه دانلود در صفحه اصلی، فایل APK نهایی را با نام دقیق `Takhte Jamshid.apk` در کنار `index.html` و در ریشه سایت قرار دهید. لینک دکمه به همین فایل اشاره می‌کند.


## بررسی و انتشار نهایی GitHub Pages

- عنوان اصلی سایت: «آموزشگاه رانندگی تخت جمشید».
- آیکون مرورگر و آیکون صفحه اصلی در فایل‌های `favicon-32.png`، `favicon-192.png` و `app-icon-512.png` قرار دارند.
- فایل `site.webmanifest` برای نام و آیکون نصب‌پذیر سایت اضافه شده است.
- برای فعال شدن دکمه دانلود اپلیکیشن، فایل واقعی APK را با نام دقیق `Takhte Jamshid.apk` در کنار `index.html` قرار دهید. این فایل در بسته حاضر نیست.
- در GitHub، تمام محتویات ZIP را در ریشه مخزن (همان جایی که `index.html` قرار می‌گیرد) بارگذاری کنید؛ فایل ZIP را به‌جای محتویاتش آپلود نکنید. سپس از Settings → Pages، انتشار از شاخه اصلی و پوشه `/ (root)` را انتخاب کنید.
- پس از انتشار، آیکون و عنوان گوگل ممکن است پس از خزش مجدد به‌روزرسانی شوند؛ نمایش فوری تضمین‌شده نیست.
